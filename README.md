# 🚀 SEO-Optimized Tech Blog 

A high-performance, 3-page static website designed specifically for tech bloggers and MERN stack developers. This project demonstrates core **On-Page SEO** principles implemented directly in HTML.

## 🌟 Key Features
* **Fully Responsive:** Mobile-first design using the Viewport meta tag.
* **SEO Ready:** Includes optimized Title tags, Meta descriptions, and Canonical links.
* **Social Optimization:** Integrated Open Graph (OG) tags for professional sharing on LinkedIn/X.
* **Semantic HTML:** Uses `<article>`, `<section>`, and `<nav>` for better search engine crawling.
* **Performance:** Lightweight code for fast loading speeds.

## 🛠️ Pages Included
1.  **Home/Blog Post:** A detailed technical article layout.
2.  **Tutorials:** A category grid for listing various tech topics.
3.  **Contact:** A user-friendly contact page with trust signals.

## 📈 SEO Checklist Implemented
- [x] Unique `<title>` for every page.
- [x] Strategic `<meta>` descriptions.
- [x] Proper Header Hierarchy (`H1` -> `H2` -> `H3`).
- [x] Image `alt` attributes for accessibility and indexation.
- [x] HTTPS-ready link structures.

## 🚀 How to Use
1. Clone the repository: `git clone https://github.com/yourusername/repo-name.git`
2. Open `index.html` in your browser.
3. Replace the placeholder text in the `<head>` with your own keywords!
